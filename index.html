SYSTEM-01 / DESKTOP
LAN Terminal & File Explorer
DEPLOYED — LIVE
Problem

Operations staff needed to browse and monitor files across 200+ networked terminals — with no central database and no internet connection, ever.

Constraints

Fully offline. No database. Portable single-executable. Role-based access for admins vs. viewers.

Build

A portable Windows desktop app with manual ping monitoring over raw sockets, direct network-share browsing, a built-in file viewer, and ZIP export — settings persisted to flat files instead of a database.

PythonCustomTkinterPyInstallerSocket / ICMP
SYSTEM-02 / MONITORING
Offline Network Monitoring Dashboard
DEPLOYED — LIVE
Problem

The team needed live, PRTG-style visibility into hundreds of LAN devices — terminals, servers, routers — without a paid monitoring license or any cloud dependency.

Constraints

Zero license cost. Zero external services. Had to feel like an enterprise NOC tool, not a script.

Build

A custom ICMP/TCP reachability engine feeding a live browser-based dashboard, with a device-tree layout inspired by commercial NOC tools — rebuilt from scratch to run entirely on the local network.

PythonICMP / TCP ProbingBrowser Dashboard
SYSTEM-03 / WEB CONSOLE
Single-File Enterprise Consoles
DEPLOYED — LIVE
Problem

Operations teams needed usable web apps — a personnel/call tracker and an ATM network console — with zero IT overhead: no server, no install, no ticket.

Constraints

Had to run as a single HTML file, entirely offline, with no backend of any kind.

Build

Browser-based apps using IndexedDB for local storage, SheetJS for spreadsheet import/export, and Chart.js for reporting — opened directly from a file and fully functional with no connection.

JavaScriptIndexedDBSheetJSChart.js
SYSTEM-04 / HEALTHCARE
Patient Tracking & EHR Tools
DEPLOYED — LIVE
Problem

Clinical staff at a public hospital were tracking patient and referral data by hand, slowing intake and losing consistency across departments.

Constraints

Needed a lightweight, local, easy-to-learn interface clinicians could adopt without training overhead — while feeding into the hospital's broader EHR rollout.

Build

A local web-based patient tracking system with simple data-entry forms and reporting views, cutting manual entry time by roughly 40% — plus contributions to the hospital's network infrastructure (racking, trunking, configuration) and its early-stage EHR rollout.

HTMLPHPMySQLNetwork Infrastructure
